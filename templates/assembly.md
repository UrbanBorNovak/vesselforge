## Construction Steps

### Phase 1: Preparation (Days 1-2)

#### 1.1 Set Up Workshop
- Clear a level workspace at least 2x the LOA
- Ensure adequate lighting and ventilation
- Set up workbenches and storage for materials
- Organize tools for easy access

#### 1.2 Study Plans
- Review the line plan carefully
- Understand all dimensions and offsets
- Mark critical measurements
- Plan the construction sequence

#### 1.3 Create Building Jig
- Build a strongback (backbone) at least LOA length
- Mark station positions on the strongback
- Ensure the strongback is level and straight
- Secure to floor or stands

### Phase 2: Frame Construction (Days 3-7)

#### 2.1 Create Station Templates
- Transfer offset data to template material
- Create full-size patterns for each station
- Label each station clearly
- Verify symmetry

#### 2.2 Cut and Assemble Frames
- Cut frame pieces from plywood
- Assemble stations with glue and fasteners
- Install floor timbers across each frame
- Fair all stations to ensure smooth lines

#### 2.3 Set Up Stations
- Position stations on the strongback at marked intervals
- Use plumb bob to ensure vertical alignment
- Brace each station temporarily
- Double-check all measurements

### Phase 3: Longitudinal Members (Days 8-12)

#### 3.1 Install Keel
- Cut and prepare keel timber
- Fit to bottom of all stations
- Secure with epoxy and fasteners
- Ensure straightness along entire length

#### 3.2 Install Chines (if applicable)
- Cut chine logs to length
- Fair to match hull shape
- Glue and fasten to stations
- Check for smooth curves

#### 3.3 Install Stringers
- Space stringers evenly along hull
- Bend to shape (may require steaming or laminating)
- Secure to each station
- Fair all surfaces

### Phase 4: Planking (Days 13-20)

#### 4.1 Prepare Plywood Panels
- Calculate panel sizes from line plan
- Cut panels with grain running fore-aft
- Number and label all panels
- Test-fit before final installation

#### 4.2 Install Bottom Planking
- Start at keel and work outward
- Use epoxy glue on all joints
- Clamp or temporarily fasten
- Stagger seams for strength

#### 4.3 Install Side Planking
- Work from bottom to top
- Maintain fair curves
- Use scarph joints for length
- Fill any gaps with epoxy filler

#### 4.4 Install Deck Beams and Decking
- Install beams at appropriate spacing
- Create proper crown for water drainage
- Plank deck with appropriate method
- Seal all deck seams

### Phase 5: Fiberglassing (Days 21-25)

#### 5.1 Surface Preparation
- Sand all surfaces smooth (80-120 grit)
- Fill any voids or defects
- Clean surfaces thoroughly
- Ensure surface is dry

#### 5.2 Apply Fiberglass
- Cut fiberglass cloth to size
- Mix epoxy per manufacturer instructions
- Wet out cloth on hull surface
- Remove all air bubbles
- Apply multiple coats as needed
- Allow proper cure time between coats

#### 5.3 Interior Treatment
- Repeat fiberglassing on interior surfaces
- Pay special attention to high-stress areas
- Ensure adequate ventilation during curing

### Phase 6: Finishing (Days 26-30)

#### 6.1 Fairing and Sanding
- Apply fairing compound to low spots
- Sand entire hull smooth (120-220 grit)
- Create smooth, fair surface
- Clean thoroughly

#### 6.2 Priming
- Apply marine primer (2-3 coats)
- Sand lightly between coats
- Ensure complete coverage

#### 6.3 Final Paint
- Apply marine paint or varnish (3-4 coats)
- Use proper application technique
- Sand lightly between coats with fine grit
- Allow adequate drying time

### Phase 7: Outfitting (Days 31-35)

#### 7.1 Install Hardware
- Through-hull fittings
- Cleats and chocks
- Rowlocks or oarlock sockets
- Rudder hardware (if applicable)

#### 7.2 Interior Finishing
- Install seats/thwarts
- Add storage compartments
- Install flotation if required
- Apply interior finish

#### 7.3 Rigging (if applicable)
- Install mast step
- Set up rigging points
- Install sail controls
- Test all systems

### Phase 8: Launch Preparation (Days 36-37)

#### 8.1 Final Inspection
- Check all fastenings
- Verify watertight integrity
- Test all moving parts
- Ensure all safety equipment aboard

#### 8.2 Weight Test
- Calculate approximate weight
- Compare to design displacement
- Adjust ballast if needed

#### 8.3 First Launch
- Choose calm conditions
- Have assistance available
- Check for leaks immediately
- Monitor stability carefully

## Troubleshooting

### Issue: Hull Not Fair
**Solution**: Check station alignment, recheck measurements, use long batten to identify high/low spots

### Issue: Epoxy Not Curing
**Solution**: Verify mixing ratio, ensure adequate temperature (minimum 60°F/15°C), check expiration dates

### Issue: Planks Won't Bend
**Solution**: Use thinner plywood, steam or laminate planks, adjust station shapes

### Issue: Leaks at Seams
**Solution**: Apply additional epoxy, use thickened epoxy for gaps, consider additional fiberglassing
